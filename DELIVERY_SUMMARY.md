### Option 2: Manual (Terminal)
```bash
# Terminal 1 - Install & Start Backend
cd backend
npm install
npm run dev

# Terminal 2 - Install & Start Frontend (in another terminal)
cd frontend
npm install
npm start

# Terminal 3 - Start MongoDB (in another terminal)
docker-compose up -d
# OR if you have MongoDB installed locally: mongod
```
